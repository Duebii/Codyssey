# 나만의 프롬프트 관리 프로그램

GenAI 미션에서 작성한 프롬프트를 카테고리, 검색어, 즐겨찾기로 관리하는 Python 콘솔 프로그램입니다.
프로그램을 실행하는 동안 새 프롬프트와 즐겨찾기 상태가 유지됩니다.

## 실행 방법

Python 3.10 이상이 설치된 환경에서 아래 명령을 실행합니다.

```powershell
python main.py
```

메뉴 번호를 입력해 기능을 선택하고, 종료하려면 `0`을 입력합니다.

현재 개발 환경 확인용 파일은 다음과 같이 실행할 수 있습니다.

```powershell
python hello.py
```

## 기능 목록

- 프롬프트 추가: 제목, 내용, 카테고리를 입력해 새 항목 등록
- 전체 프롬프트 목록 보기: 번호, 카테고리, 제목, 즐겨찾기 여부 확인
- 카테고리별 조회: 선택한 카테고리의 프롬프트만 조회
- 키워드 검색: 제목 또는 내용에서 키워드 검색
- 프롬프트 상세 보기: 제목, 카테고리, 즐겨찾기, 전체 내용과 상세 보기 횟수 확인
- 즐겨찾기 관리: 즐겨찾기 추가·해제 및 즐겨찾기 목록 확인
- JSON 저장·불러오기: 프롬프트 목록을 `prompts.json` 파일로 저장하거나 불러오기
- 카테고리별 Markdown 내보내기: `exports` 폴더에 카테고리별 목록 파일 생성
- 프롬프트 수정·삭제: 번호를 선택해 내용을 고치거나 확인 후 삭제
- 조회수 Top 3 목록: 상세 보기 횟수가 많은 프롬프트를 순서대로 확인

## 프롬프트 카테고리

| 카테고리 | 설명 |
| --- | --- |
| 텍스트 생성 | 블로그 글, 이메일, 요약 등 텍스트 생성 프롬프트 |
| 이미지 생성 | 이미지 제작을 위한 프롬프트 |
| 영상 생성 | 영상 기획과 생성에 사용하는 프롬프트 |
| 페르소나 | 특정 역할이나 말투를 설정하는 프롬프트 |
| 자동화 | 반복 업무 자동화를 위한 프롬프트 |
| 기타 | 위 카테고리에 포함되지 않는 프롬프트 |

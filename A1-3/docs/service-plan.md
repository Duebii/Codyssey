# RE:ST 서비스 기획서

## 목적과 사용자

RE:ST는 숨가쁜 일상 속, 나에게 필요한 짧은 쉼을 발견하는 공간이다. 특정 연령·성별·직업에 한정하지 않고 휴식이 필요한 모든 사람에게 부담 없는 3분 호흡 경험을 제공한다.

- 브랜드 메시지: **일상 속, 나의 틈 / A moment to rest / 쉬어가고, 발견하고, 나아간다.**
- 핵심 가치: 긴 입력이나 가입 없이 내 상태를 돌아보고, 짧은 호흡으로 쉬어갈 수 있다.
- 브랜드 콘셉트: Woody, Natural, Cozy. 따뜻한 베이지, 목재, 오후의 햇살, 차분한 올리브와 골드 베이지.
- 디자인: 제공된 확정 이미지의 배경 부분과 실제 사진을 사용했다. 사진 속 글자·버튼은 작동하는 UI로 사용하지 않는다. HTML 제목·버튼과 원형 호흡 가이드는 코드로 구현했다.

## 페이지와 이동

| 화면 | 역할 | 다음 행동 |
| --- | --- | --- |
| Home `#home` | 서비스 첫인상과 브랜드 메시지 | 시작 → About |
| About `#about` | RE:ST 소개, Relax / Refresh / Return 설명 | 아래 선택 영역에서 Personal 또는 RE:ST Care |
| Personal / Relax `#relax` | 세 가지 호흡 중 직접 선택 | 선택 → 플레이어 준비 화면 |
| RE:ST Care `#care` | 환경·상황·필요한 도움 입력 | 실제 AI 추천 → 선택된 Relax 코스로 이동 |
| 호흡 `#breathe` | 시작, 음악, 원형 가이드, 3분 타이머 | 완료 → 홈 또는 한 번 더 |

하나의 HTML 문서에서 URL 해시로 화면을 전환한다. 주요 메뉴는 Home / About / Relax / RE:ST Care이며 모바일에서는 로고가 Home 역할을 한다. 브라우저 뒤로·앞으로 가기를 지원한다. 화면 이동 시 제목 영역으로 키보드 초점을 옮기고, 플레이어를 떠나면 음악을 일시정지한다.

## 핵심 콘텐츠

| ID | 코스 | 설명 | 파일 | 세션 |
| --- | --- | --- | --- | --- |
| focus | 기본 집중 호흡 | 지금 이 순간, 마음에 집중해요. | `audio/focus.mp3` | 3분 |
| sleep | 편안한 수면 호흡 | 몸과 마음을 편안하게 해요. | `audio/sleep.mp3` | 3분 |
| relax | 긴장을 푸는 호흡 | 무거운 마음을 가볍게 해요. | `audio/relax.mp3` | 3분 |

원본 음원 길이는 약 336.04초 / 204.74초 / 63.03초다. 각 세션은 음원 길이와 무관하게 180초다. 짧은 음원은 반복하고, 긴 음원은 180초에 멈춘다. 시작 버튼을 누르기 전에는 재생하지 않는다.

텍스트와 부드러운 원형 크기 변화로 들이마시기 4초 / 내쉬기 6초를 제안한다. 세 코스 모두 같은 단순한 가이드를 사용하며, 사운드와 목적이 다르다. 편안한 속도를 우선하고, 불편하거나 어지러우면 중단하여 자연스럽게 호흡하도록 안내한다. 운영체제의 애니메이션 감소 설정을 존중한다.

## RE:ST Care의 입력·처리·출력

1. **입력**: 현재 환경(최대 40자), 현재 상황(300자), 필요한 도움(150자). 환경 선택과 도움 예시 버튼으로 입력 부담을 줄인다.
2. **프론트엔드**: 필수값과 길이를 확인하고 `fetch('/api/recommend')`로 JSON POST를 전송한다.
3. **Python**: JSON 크기와 필수값을 다시 검증하고, 서버 환경 변수의 키로 Codyssey Chat Completions API를 호출한다.
4. **AI**: `focus`, `sleep`, `relax` 중 하나와 짧은 한국어 이유를 JSON으로 반환하도록 요청한다. 형식이 올바른지 서버에서 검증한다. 새로운 코스는 만들지 않는다.
5. **서버 검증**: ID·이유·완료 상태를 검증한다. 한국어 코스명은 서버의 고정 목록에서 가져온다.
6. **출력**: 코스명과 이유, ‘이 코스로 쉬어가기’ 버튼. 해당 코스를 선택한 Relax 화면으로 이동한다. 음악은 여전히 사용자의 시작 클릭이 필요하다.

사용자 입력은 추천 요청 시 Codyssey AI 서비스로 전송된다. 서비스의 DB나 브라우저 저장소에는 저장하지 않는다. 제공자 측 보관 정책은 해당 서비스의 정책을 따른다. 서버 로그에는 요청 식별자·HTTP 상태·오류 종류만 남긴다.

## 실패 처리 기준

| 상황 | 처리 |
| --- | --- |
| 빈 입력 | API 호출 전에 추가 입력 안내와 해당 입력 초점 |
| API 키 없음 | HTTP 503, 연결 준비 안내와 Personal 경로. 추천을 생성하지 않음 |
| API 4xx/5xx·잘못된 키·통신 오류 | 정해진 연결 안내, 다시 시도 가능 |
| AI가 허용하지 않은 ID·형식·빈 이유 반환 | HTTP 502, 추천 결과를 표시하지 않음 |
| 모델의 거절·미완료 응답 | HTTP 502, 일반 오류 안내 |
| 요청 지연 | 로딩 문구, 중복 클릭 차단, 프론트 25초 제한 |
| AI 연결 시간 초과 | 서버 네트워크 대기 20초 제한, HTTP 504 |
| 음악 로딩 실패 | 타이머 중지와 재시도 안내 |
| 추천 요청 중 화면 이동 | 요청 취소, 늦게 도착한 응답 무시 |

임시 추천은 서비스 코드에 없다. 테스트 파일에서만 모의 응답을 사용하고, 해당 스크린샷에도 실제 AI 추천이 아니라는 문구를 표시한다.

## 이번 MVP 범위와 현재 상태

구현: Home / About / Relax / Care 입력·결과 UI, 메뉴, Personal 선택, 세 사운드 재생, 3분 호흡·완료, Python 실제 AI 호출 코드, 실패 처리, 반응형, 로컬 실행 서버, 테스트와 문서.

**Codyssey API를 통한 실제 추천과 코스 이동은 로컬에서 확인했다. GitHub main 업로드와 Vercel 배포를 완료했으며, 공개 주소의 세 음원이 HTTP 200으로 응답함을 확인했다(2026-09-11). 공개 사이트 전체 사용자 흐름 검증은 추가로 필요하다.** 서비스에 로그인·DB·개인화 통계·커머스는 없다.

## 향후 확장

Refresh(6분 ASMR), Return(9분 명상), Archive, DB, 개인화 추천, 커머스는 향후 계획이다. Refresh와 Return은 이번 화면에서 ‘준비 중’으로만 소개한다. TTS·새 콘텐츠 생성도 이번 범위에 포함하지 않는다.

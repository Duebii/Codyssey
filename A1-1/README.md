# 나만의 프롬프트 관리 프로그램

Python으로 만드는 콘솔 기반 프롬프트 관리 프로그램입니다.

## 실행 방법

Python 3.10 이상을 설치한 뒤, 프로젝트 폴더에서 다음 명령어를 실행합니다.

```bash
python main.py
```

Windows 환경에서 Python Launcher를 사용하는 경우에는 다음 명령어를 사용할 수 있습니다.

```bash
py main.py
```

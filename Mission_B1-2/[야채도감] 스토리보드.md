# 스토리보드

# AI 기반 브랜드 광고 제작 프로젝트

## 프로젝트명

**야채도감(Vegetable Guide) AI 광고 제작**

---

# 1. 프로젝트 개요

## 브랜드명

**야채도감**

## 브랜드 소개

야채도감은 다양한 야채의 영양성분, 효능, 시너지 식재료, 추천 레시피, 주의사항 등을 쉽고 재미있게 알려주는 AI 기반 야채 정보 서비스이다.

복잡한 건강 정보를 누구나 쉽게 이해할 수 있도록 직관적인 UI와 귀여운 캐릭터를 활용하여 건강한 식생활을 돕는 것을 목표로 한다.

---

# 2. 브랜드 아이덴티티

## 타겟

- 건강한 식습관에 관심 있는 20~30대
- 아이를 키우는 부모
- 건강 정보를 쉽게 알고 싶은 일반 사용자

---

## 톤앤매너

- 밝고 따뜻한 분위기
- Pixar 스타일의 3D 애니메이션
- 친근하고 귀여운 캐릭터
- 건강하고 신뢰감 있는 브랜드 이미지

---

## USP(차별화 포인트)

- AI 기반 야채 정보 제공
- 영양성분, 효능, 시너지 식품을 한 번에 확인
- 귀여운 캐릭터를 활용한 쉬운 정보 전달
- 누구나 쉽게 사용할 수 있는 직관적인 UI

---

# 4. 전체 스토리 구조

광고는 문제 제시 → 흥미 유발 → 해결 → 브랜드 소개의 구조로 구성하였다.

```
브로콜리가 말을 한다.

↓

농부가 놀란다.

↓

야채도감으로 촬영한다.

↓

야채도감 앱이 정보를 알려준다.
```

짧은 10초 안에서도 자연스럽게 브랜드를 소개하도록 구성하였다.

# 7. 제작 전략

영상 생성은 크레딧 소모가 많기 때문에 이미지 단계에서 전체 스토리보드를 먼저 확정하였다.

이후 동일한 캐릭터와 스타일을 유지한 상태에서 영상을 생성하여 재생성 횟수를 최소화하였다.

또한 모든 장면의 배경과 조명, 캐릭터 디자인을 동일하게 유지하여 광고의 완성도를 높였다.

# ✨ 프롬프트 수정 기록 (추가 권장 항목)

### 수정 전

Scene 2에서 바로 스마트폰 촬영 장면(Scene 3)으로 전환하였다.

```
브로콜리 등장
↓

농부 놀람
↓

바로 스마트폰 화면
```

---

### 수정 후

Scene 2와 Scene 3 사이에 **브리지 컷**을 추가하였다.

```
브로콜리 등장
↓

농부 놀람
↓

농부가 스마트폰을 들어 올림
(손 클로즈업)

↓

스마트폰 촬영 화면
```

---

### 수정 이유

처음에는 놀라는 장면에서 바로 스마트폰 화면으로 전환되어 화면 연결이 다소 급하게 느껴졌다.

이를 개선하기 위해 **농부가 스마트폰을 들어 올리는 1초 브리지 컷**을 추가하였다.

이를 통해 사용자가 '왜 스마트폰을 사용하는지'를 자연스럽게 이해할 수 있었으며, 장면 간 연결이 부드러워지고 광고의 몰입감이 향상되었다.

또한 실제 모바일 앱 광고처럼 자연스러운 흐름을 구현할 수 있었다.

# 9. 프롬프트 수정 전 / 후

## 수정 대상

**Scene 3 (스마트폰 촬영 장면)**

### 수정 전

```
Animate this exact reference image.

The smartphone remains centered.

The broccoli inside the app happily waves and smiles.

The app interface softly glows.

Healthy icons gently appear.

The farmer smiles proudly.

Camera slowly zooms toward the phone.
```

### 문제점

- 영상 생성 과정에서 앱 내부의 **한글 텍스트가 깨지는 현상**이 발생하였다.
- UI와 아이콘이 새롭게 생성되면서 화면이 원본과 달라졌다.

---

### 수정 후

```
Animate this exact reference image.

Keep the smartphone perfectly centered.

Treat the phone interface as a locked static image.

Do not regenerate text, icons, logos, or buttons.

Only animate the broccoli character.

The broccoli smiles, blinks, and waves naturally.

The camera slowly pushes toward the smartphone.

Keep everything identical to the reference image.
```

### 수정 이유

앱 화면(UI)을 하나의 고정된 이미지처럼 유지하도록 프롬프트를 수정하였다.

텍스트와 아이콘의 재생성을 방지하여 한글이 깨지는 문제를 해결했고, 브로콜리 캐릭터만 자연스럽게 움직이도록 설정하여 광고의 완성도를 높였다.

# 11. 캐릭터 및 스타일 일관성 유지 전략

- 모든 장면에서 동일한 브로콜리 캐릭터를 유지하였다.
- Pixar 스타일의 3D 애니메이션 톤을 모든 프롬프트에 공통 적용하였다.

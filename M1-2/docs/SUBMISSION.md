# M1-2 · 김실장 제출 요약

미션: **AI Agent 개발: 나만의 AI 비서 구축**

## 제출 소개문

김실장은 여러 일을 병행할 때 우선순위를 정하고 실행 전략을 세우며, 반복 업무의 자동화 방법을 설계하는 AI 업무 전략 비서입니다. 사용자가 질문하면 저장된 작업 기록의 요약과 현재 목표·마감·가능 시간을 함께 참고해 답합니다.

프리랜서·취업 준비·창업 준비를 병행하는 가상 사용자의 작업 기록 150건을 만들었습니다. 날짜별 소요 시간과 분야별 비중, 반복 작업, 예상 대비 초과 시간, 최근 추세를 파이썬으로 분석하고 Firestore에 요약을 저장합니다. 채팅 요청마다 최신 요약을 시스템 프롬프트에 주입해 GPT가 데이터를 참고하게 했습니다.

FastAPI 백엔드는 라우터·서비스·스키마·저장소로 나눴고 Pydantic으로 입력을 검증합니다. 웹은 프레임워크 없이 HTML/CSS/JavaScript로 구현했습니다. Firestore CRUD, 대화 자동 저장·불러오기, Render·Vercel 배포를 완료했습니다. 자동화는 설계와 검증 절차를 제안하며 외부 도구를 직접 실행하지 않습니다.

## 데이터 출처와 제출 허용

- 출처: 실제 개인 기록이 아닌 합성 데이터(`source: synthetic`). 고정 시드 `1021`로 생성합니다.
- 범위: 2026-08-26 ~ 2026-10-20, 150건·6,524분. 날짜가 같은 별도 작업도 각각 한 데이터 포인트입니다.
- 허용 확인: **2026-10-28 사용자가 과제 담당자에게 더미데이터 제출 허용을 확인받았다고 알려 주었습니다.** 담당자의 원문을 직접 검토했다는 뜻은 아닙니다.
- 해석 한계: 가상 패턴 발견은 실제 생산성이나 자동화 효과를 입증하지 않습니다. 미기록 날짜는 0분 작업·휴식으로 단정하지 않습니다.

## 3분 시연 순서

1. 웹의 기록 요약에서 기간·건수·총 시간·추세를 확인합니다.
2. 이전 상담에서 `[9단계 검증·전략]`을 열어 최초 90분과 시간·마감 변경 후 45분 계획을 비교합니다. 저장된 대화를 여는 동작은 GPT를 호출하지 않습니다.
3. `[10단계 웹 확인]` 상담에서 150건·6,524분을 반영한 질문·답변과 근거를 확인합니다.
4. 작업 기록 화면에서 추가·수정 입력과 저장된 목록을 확인합니다. 제출 캡처에는 임시 기록의 12분→18분 수정 결과가 있고, 검증 뒤 해당 기록은 삭제했습니다.
5. 새로고침 후 이전 상담 목록에서 같은 상담을 선택해 질문·답변·조건을 다시 불러옵니다.

새 질문을 전송하면 실제 GPT 호출과 비용이 발생할 수 있습니다. Render 무료 서버의 첫 접속은 약 1분 지연될 수 있습니다. 현재 서비스는 로그인 없는 공개 가상 데이터 시연용이므로 실제 개인·업무 비밀은 입력하지 않습니다.

## 확인한 범위

2026-10-27 Python 221개·Node 14개 시험을 통과했습니다. 별도로 실제 Firestore·GPT·배포 웹을 연결해 CRUD·요약·상담·대화 복원을 확인했습니다. 배포 시험에서 기존 작업 150건과 기존 상담 11개를 보존했고 새 검증용 상담 2개를 남겼습니다. 캡처는 2026-10-27 검증 시점의 화면이며 현재 실시간 상태를 뜻하지 않습니다.

2026-10-28 제출 자료 점검에서는 문서 8개·내부 링크 99곳·필수 캡처 3개, 원본 150건 보존, 생성 결과 재현과 환경 설정 예시를 확인했습니다. 배포 웹·설정 파일·서버 상태·Swagger가 200을 반환했고 OpenAPI에 필수 API 동작 10개가 있음을 확인했습니다. 읽기 요청만 사용했으며 이 단계의 유료 GPT 호출·기록 변경은 0회입니다. 공개 후보 파일과 배포 파일에서 실제 키 문자열 일치는 없었습니다.

보너스의 Function Calling·MCP/GPT Actions·실제 자동화 실행, 로그인·사용자별 데이터 분리는 구현 범위에 포함하지 않았습니다. 실제 업무 활용도는 실제 작업을 대상으로 후속 검증할 항목입니다.

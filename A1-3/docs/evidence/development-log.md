# 4번 증빙 — AI 코딩 도구 사용 과정

이 문서는 실제 Codex 작업 대화의 일부 발췌와 도구 실행 요약입니다. 전체 대화를 그대로 내보낸 파일은 아닙니다. 계정 정보·API 키는 포함하지 않았습니다.

## 실제 대화 발췌

사용자:

> A1-3에서 작업해줘 음악과 이미지들은 이 폴더 안에 적혀있어

Codex:

> A1-3에는 디자인 이미지 9개와 음원 3개가 있고, 아직 웹 코드는 없습니다. 기존 Git 저장소와 다른 폴더의 변경사항도 확인했습니다.

사용자 후속 요청:

> 우선 API 키와 GitHub·Vercel 로그인 설정은 나중에 진행하겠습니다. 현재는 A1-3 폴더에서 화면, 음악 플레이어, 서버 등 계정 설정 없이 구현 가능한 부분을 먼저 작업해 주세요.

> 기존 다른 폴더나 파일은 수정하지 말아 주세요. 로컬 테스트까지 완료한 뒤, 제가 직접 해야 하는 API 키 설정과 GitHub·Vercel 로그인 절차를 초보자도 따라 할 수 있도록 한 단계씩 안내해 주세요.

Codex:

> 이번에는 A1-3 안에서 계정 없이 가능한 구현과 로컬 테스트까지 완료하고, API 키·GitHub·Vercel 설정은 따라 하기 안내로 남기겠습니다. 키가 없으면 추천을 만들어 보여주지 않고 연결 안내와 직접 선택 경로를 제공하겠습니다.

Codex:

> 서버 테스트 13개가 통과했고, 3개 음원 모두 실제 브라우저에서 재생·일시정지·재개를 확인했습니다. 320px부터 1440px까지 네 가지 화면 크기에서 가로 넘침도 없었습니다.

## 도구 실행과 구현 과정 요약

1. 첨부 미션, `A1-3` 파일 목록, 기존 Git 상태·remote·브랜치를 확인했습니다. 다른 과제의 기존 변경사항을 유지했습니다.
2. 제공 이미지들을 열어 글자가 없는 배경 영역과 실제 사진을 확인했습니다. 음원은 `audio/`로 복사했고 원본은 보존했습니다.
3. `codex/rest-mvp` 작업 브랜치를 만들었습니다. 계정 설정은 사용자의 후속 요청에 따라 보류했습니다.
4. Home / About / Relax / Care HTML, 따뜻한 베이지·목재 색상의 CSS, URL 해시 메뉴를 구현했습니다.
5. Vanilla JavaScript로 실제 MP3 플레이어, 일시정지·재개·음소거·음량·3분 타이머·완료 UI를 구현했습니다.
6. 공식 OpenAI·Vercel 문서를 열어 확인한 후 `api/recommend.py`에 실제 API 요청 코드를 구현했습니다. Schema 및 서버 검증, 키 미설정 503, 오류·지연·취소를 처리했습니다.
7. Python 표준 라이브러리로 로컬 서버를 실행했습니다. `.env`·서버 코드·문서는 HTTP 공개 대상에서 제외했습니다.
8. Python 단위·HTTP 테스트 13개를 통과했습니다. Chrome + Playwright로 네 가지 화면 크기를 검사하고 스크린샷을 저장했습니다.
9. 실제 음원 3개를 재생했습니다. 63초 음원이 반복되는 **실제 180초** 세션에서 03:00 완료·음악 정지·재시작을 확인했습니다. 타이머를 빠르게 돌린 테스트가 아닙니다.
10. README, 서비스 기획서, 학습 설명, API 키·GitHub·Vercel 설정 안내와 증빙 목록을 작성했습니다.

## API 연결 오류를 수정한 과정

사용자:

> api 키 저장했는데 왜 연결준비중이야?????

사용자는 이어서 Codyssey API 콘솔 화면을 제공하고 다음과 같이 요청했습니다.

> 이걸로 수정해줘

수정 결과:

- 처음에는 저장된 키를 OpenAI 본사 API로 보내 인증이 실패했습니다. 제공된 콘솔 화면을 확인한 뒤 Codyssey용 키라는 점을 파악했습니다.
- `api/recommend.py`의 연결 주소를 `https://copa.codyssey.kr/v1/chat/completions`로, 기본 모델을 `gpt-5-mini`로 변경했습니다.
- Chat Completions 응답에서 코스 ID와 추천 이유를 읽도록 수정하고, 허용되지 않은 코스·잘못된 JSON·미완료 응답을 거부하도록 검증했습니다.
- 기존 키를 유지한 채 서버를 재시작하고 실제 추천 HTTP 200, 결과 표시, 추천 코스 이동을 확인했습니다. 변경된 서버 테스트 13개도 통과했습니다.

관련 증빙: [실제 호출 검증 기록](codyssey-live-report.json), [실제 추천 결과](03-ai-result-computer-use.jpg).

## Computer Use로 실제 화면을 캡처한 과정

사용자:

> 3-6은 컴퓨터 use 사용해서 직접 캡쳐해서 저장해줘

초기에는 도구가 브라우저 주소를 확인하지 못해 캡처가 중단됐습니다. 이때는 캡처를 완료했다고 기록하지 않았습니다.

사용자:

> 재시작했어 다시 요청한 작업 해주라라

재연결 후 Chrome에서 다음 순서로 직접 조작했습니다.

1. 로컬 RE:ST Care를 열고 최신 화면을 불러왔습니다.
2. `집 / 오랜 작업을 마치고 잠깐 쉬고 싶어요. / 긴장을 내려놓고 싶어요.`라는 검증용 문장을 입력했습니다.
3. 추천 버튼을 누르고 실제 로딩 상태와 AI 결과를 캡처했습니다.
4. ‘이 코스로 쉬어가기’를 눌러 ‘긴장을 푸는 호흡’이 선택되는 것을 확인했습니다.

## README에 서비스 화면을 정리한 과정

사용자:

> readme에 캡쳐한 증거 사진중에 서비스 소개할 주요화면만 추려서 데스크탑+모바일 섞어서 작업해줘

데스크톱 Home·실제 AI 추천 결과와 모바일 화면을 골라 설명을 추가했습니다. 이후 사용자가 HTML 표가 코드로 보이는 화면을 보내 다음과 같이 요청했습니다.

> 모바일 캡쳐이미지로 수정해줘

현재 README는 HTML 표 대신 일반 마크다운 이미지로 모바일 화면을 연결합니다. 이는 앱 기능 변경이 아니라 문서의 이미지 표시 방식 수정입니다.

## 제출 범위와 남은 작업

이 자료는 **대화 발췌와 작업 기록 형식의 4번 증빙**입니다. Codex 앱의 원본 대화 화면을 캡처한 이미지나 전체 대화 내보내기 파일은 아닙니다. 위에 연결된 JPG는 실제 서비스 화면의 직접 캡처입니다.

실제 AI 추천은 로컬에서 확인했습니다. GitHub 원격 push와 Vercel 공개 배포는 아직 수행하지 않았습니다. 과거의 모의 추천 검사 자료는 `TEST-ONLY` 이미지와 테스트 기록으로 구분합니다.

# 프로젝트 작업 안내

이 프로젝트는 Python으로 만드는 콘솔 기반 프롬프트 관리 프로그램이다.

## 개발 원칙

- Python 3.10 이상과 표준 라이브러리만 사용한다.
- 코드는 기능별 함수로 분리한다.
- 이해하기 쉬운 한글 메시지와 변수명을 사용한다.
- 새 기능을 추가할 때는 기존 메뉴와 데이터 구조가 정상 동작하는지 함께 확인한다.
- 프로그램 실행 중 추가한 데이터와 즐겨찾기 상태는 종료 전까지 유지한다.

## 데이터 형식

프롬프트는 리스트 안의 딕셔너리로 관리한다. 각 프롬프트에는 아래 키가 필요하다.

```python
{
    "title": "제목",
    "content": "프롬프트 내용",
    "category": "카테고리",
    "favorite": False
}
```

## 구현 및 테스트

- 빈 입력, 잘못된 메뉴 번호, 존재하지 않는 프롬프트 번호를 안전하게 처리한다.
- 기능을 구현한 뒤 직접 실행해 정상 동작을 확인한다.
- 외부 라이브러리를 추가하거나 파일 저장 기능을 넣기 전에는 요구사항을 먼저 확인한다.

## Git 규칙

- 기능 단위로 작고 의미 있는 커밋을 만든다.
- 커밋 메시지는 변경 내용을 간단히 설명한다.
- 별도 브랜치에서 기능을 작업한 뒤 `main` 브랜치에 병합한다.
- 민감 정보, 개인 설정 파일, 과제 안내 파일(`subject.md`)은 커밋하지 않는다.

## 문서

- `README.md`에는 프로그램 소개, 실행 방법, 기능 목록, 카테고리 설명을 작성한다.
- `worklist.md`의 완료한 항목은 체크 표시로 갱신한다.

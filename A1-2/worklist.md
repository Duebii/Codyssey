## 2. CLI와 입력값 검증 구현

- [x] `travel_planner.py` 파일을 만든다.
- [x] `argparse`로 `--date` 또는 `-date` 옵션을 받는다.
- [x] 날짜가 입력되지 않은 경우 사용법을 출력한다.
- [x] 날짜가 `YYYY-MM-DD` 형식인지 검증한다.
- [x] 잘못된 날짜 형식일 때 안전하게 종료되는지 실행해 확인한다.

## 4. 1차 여행 추천 기능 구현

- [x] 날짜를 포함한 LLM 프롬프트를 작성한다.
- [x] 추천 지역, 날씨, 행사·축제, 추천 이유를 JSON 형식으로 요청한다.
- [x] LLM 응답을 JSON으로 파싱한다.
- [x] `recommended_city`, `weather`, `events`, `reason` 필수 키를 검증한다.
- [x] JSON 파싱 실패 시 JSON만 다시 요청하는 재시도 로직을 1회 구현한다.
- [x] 정상 JSON 응답과 파싱 실패 응답을 각각 테스트로 확인한다.

## 5. 맛집 검색 기능 구현

- [x] 1차 추천 결과의 `recommended_city`를 검색어로 사용한다.
- [x] 지도/장소 API 요청 함수를 구현한다.
- [x] 검색 결과에서 이름, 주소, 카테고리, URL, 좌표 정보를 정리한다.

- [x] 장소 검색 오류를 `errors` 목록에 기록한다.

# Mission_B1-2
**[멀티모달 콘텐츠 제작]**

이제 텍스트로 이미지를 한 장 만드는 것은 누구나 하는 일이 되었습니다. 

하지만 그 이미지들에 생명력을 불어넣어 하나의 '완성된 브랜드 경험'을 만드는 것은 차원이 다른 문제입니다.

광고, 티저 영상, 숏폼 캠페인처럼 시각과 청각을 동시에 사로잡는 몰입감은 어떻게 설계되는 걸까요? 

단순히 운 좋게 좋은 결과물이 나오기를 기다리는 것이 아니라, 내가 원하는 그림과 소리를 AI로 정교하게 구현해낼 수 있다면 어떨까요?

이번 미션의 목표는 기획 의도가 프롬프트를 거쳐 최종 영상으로 구현되기까지의 전체 제작 파이프라인을 스스로 설계하는 데 있습니다.

가상의(또는 실제) 브랜드 1개를 선택하고, 스토리보드(기획 문서)를 만든 뒤, AI 도구만을 주된 소스로 활용하여 10초 이내의 광고 영상을 완성합니다.

중요한 것은 “도구를 많이 쓰는 것”이 아니라, 기획 의도 → 프롬프트 → 결과물 → 통합 편집으로 이어지는 파이프라인을 스스로 설계하고 왜 그렇게 의사결정했는지 설명하는 것입니다.

또한, 멀티모달 제작에서 빈번히 발생하는 문제(캐릭터/화풍 불일치, 해상도·비율 혼재, 오디오 톤 미스매치, 크레딧/대기열 이슈)를 고려해 현실적인 제작 전략을 세우고 적용합니다.
